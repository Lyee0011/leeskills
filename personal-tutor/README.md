# 自我解释skill

让 AI 根据你的理解追问，帮你整理每次学习留下的问题和进度，逐步把零散知识连起来。

由小伊整理与分享。核心方法是自我解释，加上时间与范围管理、学习记录、延迟回忆和知识串联。

## 直接开始

把下面这句话发给你的 AI：

> 请读取 https://github.com/Lyee0011/leeskills/tree/main/personal-tutor ，按照其中的 SKILL.md 帮我建立学习库。

AI 会先确认保存位置，把基础目录和空模板建齐。你可以暂时不选课题；想开始学习时，再告诉它想学什么、今天有多少时间。

需要使用能读取网页或文件、并能在你指定位置创建目录和读写文件的 AI 工具。模型可以在云端运行，关键是工具具备文件操作能力。只支持聊天的工具也能用问答方法，但记录需要手动保存。

如果 AI 无法读取 GitHub 目录页，可以发给它 [SKILL.md 原文链接](https://raw.githubusercontent.com/Lyee0011/leeskills/main/personal-tutor/SKILL.md)，或下载本文件交给它。支持安装 Skill 的工具，也可以按该工具的安装方式添加整个 `personal-tutor` 目录。

## 四步怎么用

1. **建好学习库（第一次用）**：先准备导航、共享方法、空白课题模板和日志位置。
2. **定好学习范围**：根据你已有的基础、可用时间，选一个本次能推进的问题。
3. **自我解释与追问**：先说你怎么理解；完全陌生时先听必要讲解。AI 一次追问一个关键问题，纠错后请你重新解释或换个例子。
4. **回顾、记录与串联**：结束前不看答案做自测，留下实际理解、没懂的地方和下次入口。每周再从旧记录中回忆、寻找联系。

## 初次建立的结构

```text
学习库/
├─ README.md
├─ 自我解释skill.md
├─ AGENTS.md
├─ 跨课题串联日志/
│  └─ 模板.md
├─ 课题模板/
│  ├─ 课题进度.md
│  ├─ 问题库.md
│  ├─ 知识点随记.md
│  ├─ 彩蛋库.md
│  ├─ 每日学习日志/
│  │  └─ 模板.md
│  └─ 串联日志/
│     └─ 模板.md
└─ 你选定的课题/  ← 选题后创建，同样建齐以上六项
```

真实课题直接放在学习库第一级，可以同时学多个课题。没有选题时也会先建立完整模板。模板不算学习记录，实际问答随后写入。

新会话时，让 AI 先读**你自己的学习库 README**，再按导航读取课题进度和相关记录，就能接着学。GitHub 提供方法，你的学习记录保存在自己指定的位置。

## 给 AI 的读取入口

请完整读取 [SKILL.md](SKILL.md)。其中包含建库清单、教学流程、时间检查、记录字段及中断恢复规则，不要只按本页简介执行。

- [完整空模板](assets/library/)：新库和新课题的文件底稿。
- [可选建库脚本](scripts/init_library.py)：Python 3 标准库，无第三方依赖；只补缺，不覆盖已有文件。请先阅读，再在用户指定位置运行。
- 初次建库：`python scripts/init_library.py "学习库路径"`
- 同时建立已选课题：`python scripts/init_library.py "学习库路径" --topic "经济学"`

脚本输出后，继续按 SKILL.md 核对内容、填写用户已说明的目标，并补全导航。已有库的课题与历史文件不搬移、不删除。

## 关于方法

自我解释的研究支持学习者主动解释有助于学习；这不等于整套 AI 工作流已经过实验验证，也不承诺固定倍数的提升。讲解与纠错仍需核对可靠来源，AI 的肯定不等于已经学会。

- Chi 等（1994）：[Eliciting Self-Explanations Improves Understanding](https://doi.org/10.1207/s15516709cog1803_3)
- Bisra 等（2018）：[Inducing Self-Explanation: a Meta-Analysis](https://doi.org/10.1007/s10648-018-9434-x)

我会继续使用和调整这套方法。哪里别扭、哪里对你有用，欢迎在 [Issues](https://github.com/Lyee0011/leeskills/issues) 里告诉我。
